## Generate the reviewable source package

From repository root:

```bash
backend/venv/bin/python scripts/package_submission.py --output submission/CartPilot-submission.zip
```

This packages approved source/docs/tests/screenshots from the working tree, including
untracked implementation files from earlier phases. It excludes .env, .git, dependency
folders, caches, builds, logs, DB files/dumps and unrelated prompt.txt. Archive includes
SUBMISSION_MANIFEST.json with per-file SHA-256, branch/HEAD and working-tree provenance.
The package is a source snapshot, not a claim that later phases were committed at HEAD.
Inspect ZIP integrity/list/manifest before handing it in. The generated submission/*.zip archive is ignored by Git.
