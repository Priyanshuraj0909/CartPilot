# PHASE 10 — CROSS AGENT ORCHESTRATION

## Goal

Allow CartPilot to reason across all agents.

Example merchant goal:

"Increase revenue while maintaining healthy inventory."

Orchestrator:

1. Sense store.
2. Identify opportunities.
3. Run Pricing Agent.
4. Run Restock Agent.
5. Run Promotion Agent.
6. Run Listing Agent.
7. Compare results.
8. Detect conflicts.
9. Prioritize actions.
10. Validate policies.
11. Create unified action plan.
